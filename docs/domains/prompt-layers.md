# 分层提示词（现行事实）

> 本文是该功能域**现行状态**的权威描述（2026-09-10 自 AGENTS.md 拆出）；改动该域时同步本文。「为什么这样设计」的决策考古见 `docs/superpowers/specs/archive/`。

分层提示词（2026-08-31 起为四层模型）：层栈固定 = identity（原生，可编辑覆盖式：waterfall 命中时若覆盖非空且非 subagent 且段文本等于原生常量则整份替换，空 = 还原原生；仅主 Agent 生效）/ 模型层（内置 `prompt-stack:base` order 0，只读）/ persona（`prompt-stack:persona` order 10，可编辑）/ 动态层（contexts/工具段，只读展示）。模型层文本 = 命中规则 `overrides.base` ?? 内置默认文本；`base` 是保留层名、不进存储、仍是 overrides 合法目标（cordis.yml 存量零破坏）；`model-notes`（order = 最大层 order + 1）自动层，规则 append 命中时渲染。persona 改普通段，不再填 `deployment:persona` 槽位（槽位归还原生：cordis.yml 的 `systemPrompt.persona` 配置了则渲染在 identity 后、模型层前，与 UI persona 层各自独立）；bot 会话角色 persona 用 scoped 同名段 `prompt-stack:persona` shadow 全局段；委派子 Agent persona = 契约段 + 模型层文本（按子的模型命中）+ 角色 persona + 规则 append，全局 persona 不泄漏给子 Agent。存储 `prompt_layers` 表单行（仅 persona 层文本 + 可选 `identity` 覆盖字段，identity 仅非空时落字段），打开时按种子 reconcile（丢弃 base/domain/task 已编辑文本、保留 persona）。设计依据：`docs/superpowers/specs/archive/2026-08-31-prompt-layer-simplification-design.md`。
