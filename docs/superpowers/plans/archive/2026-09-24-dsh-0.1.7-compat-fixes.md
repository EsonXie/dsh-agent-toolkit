### Task 5: agent-team preset 迁移到声明式注册（readDocument + register）

0.1.7 重构了 preset 体系（#4569）：`@deepseek-ai/dsh-agent-presets`（文件根扫描 + `roots` + `read(id)`）整体删除，preset 变为 `@deepseek-ai/dsh-agent-preset-registry` 服务（npm 名 `@deepseek-ai/dsh-agent-preset-registry`，服务键仍为 `ctx.agentPresets`）上的**声明式注册**——内置 preset 改为 bundle patch 里的 `@deepseek-ai/dsh-agent-preset` 行（`packages/bundle/web-app/presets/standard.patch.yml` 等），不再扫描任何文件目录。

对插件的影响与迁移设计：
- `read(id)` → `readDocument(id)`：返回 `{ agentPreset, content, name?, description? }`，`content` 是以 Loader 方言 dump 的 plugins 列表 YAML 文本（`!!js` 原样保留），正好接现有 `disableSubagentRows` 文本改写。
- 写目录 → `register(definition)`：`disableSubagentRows` 产物用 `js-yaml` 的 `load(text, { schema: entryListSchema })` 解析（`entryListSchema` 来自 `@deepseek-ai/cordis-plugin-include`，已是 toolkit devDep；它把 `!!js` 解析为 `JsExpr` 对象，`PresetDefinition.plugins` 的 `disabled` 字段允许 `JsExpr`），然后 `ctx.agentPresets.register({ id, name, description, plugins })`。register 返回 disposer promise，直接交给 `ctx.effect`（cordis 4 支持异步 effect，卸载自动注销）——天然替代旧的 marker 文件/自愈重写机制。
- 旧文件协议（`roots`、user root、`agent.cordis.yml`/`preset.yml` 目录、MARKER_FILE、`LEGACY_BOT_PRESET_ID` 目录清理）在 0.1.7 宿主上已无任何读取方，整体删除；`team-preset.test.ts` 中对应测试用例随之删除/改写。
- `register` 幂等性：同名 id 重复 register 的宿主行为未在本调研中坐实——迁移后首启验证（任务 8 实测步骤）若发现重复注册报错，再在插件侧加 `list()` 预查。
- `expandHomePath` 导入随 roots 删除而移除。

`AgentPresetsLike` 改为：

```ts
/**
 * agentPresets 服务的结构类型。可选服务经 ctx.get 读取（宿主约定：可选服务用
 * ctx.get，不进 inject），结构类型避免对 @deepseek-ai/dsh-agent-preset-registry 的依赖
 *（bots/index.ts 的 WorkspaceRegistryLike 先例）。
 */
interface AgentPresetsLike {
  readDocument(id: string): Promise<{ content: string }>
  register(definition: {
    id: string
    name?: string
    description?: string
    plugins: readonly unknown[]
  }): Promise<() => Promise<void>>
}
```

`setupAgentTeamPreset` 主体改为：

```ts
export async function setupAgentTeamPreset(ctx: Context, config: AgentTeamPresetConfig): Promise<void> {
  if (!config.enabled) return
  const warn = (msg: string): void => { ctx.logger.warn(msg) }
  // 无 agentPresets 服务的宿主：静默跳过（无 subagent/team_delegate 工具竞争问题）。
  const agentPresets = ctx.get('agentPresets', false) as AgentPresetsLike | undefined
  if (agentPresets === undefined) return
  if (!PRESET_ID.test(config.id)) {
    warn(`dsh-agent-toolkit: agentTeamPreset.id "${config.id}" 不是合法 preset id，跳过 agent-team 生成`)
    return
  }
  let source: string
  try {
    source = (await agentPresets.readDocument(config.source)).content
  } catch (error) {
    warn(`dsh-agent-toolkit: 读取源 preset "${config.source}" 失败，跳过 agent-team 生成：${error instanceof Error ? error.message : String(error)}`)
    return
  }
  let plugins: unknown
  try {
    plugins = yaml.load(disableSubagentRows(source, warn), { schema: entryListSchema })
  } catch (error) {
    warn(`dsh-agent-toolkit: 解析派生 composition 失败，跳过 agent-team 生成：${error instanceof Error ? error.message : String(error)}`)
    return
  }
  // 注册生命周期交给 ctx.effect：插件卸载（含 HMR 重组）时宿主自动注销 preset，
  // 替代 0.1.5 时代的标记目录与自愈重写。
  ctx.effect(
    () => agentPresets.register({ id: config.id, name: config.name, description: config.description, plugins: plugins as readonly unknown[] }),
    'dsh-agent-toolkit: agent-team preset',
  )
}
```
